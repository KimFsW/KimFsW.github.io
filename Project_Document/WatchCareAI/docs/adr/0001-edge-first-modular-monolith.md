# ADR 0001：边缘优先 + 模块化云端单体 + 原生 iOS

- 状态：已接受（2026-08-03，随设计方案 v1.0 冻结）
- 来源：《守望 AI 软件设计及编写方案》1.1 / 12 节

## 背景

iOS 后台任务由系统调度，无法承担全天候视频解码与 AI 推理；
首版团队规模小，直接拆微服务会显著增加部署与运维成本；
家庭视频属于高度敏感数据，不应默认持续上传云端。

## 决定

1. 家庭边缘节点负责持续分析，iOS App 只做监护终端；
2. 云端首版采用模块化单体（FastAPI），模块间只通过应用服务与领域事件协作；
3. 边缘 ↔ 云端事件通道用 MQTT over TLS（mTLS、QoS 1、幂等消费）；
4. iOS ↔ 云端用 HTTPS REST，报警用 APNs；
5. 连续原始视频不上传云端，只上传事件证据且可配置关闭。

## 后果

- 正面：职责边界清晰，隐私风险最小化，iOS 被系统终止后报警链路仍可用；
- 代价：需要维护边缘硬件的部署与升级通道；模块化单体后期需按压力点拆分；
- 约束：领域层不得依赖具体框架（SwiftUI / FastAPI / ONNX Runtime），
  跨模块禁止直接改对方数据表，接口契约统一放在 `contracts/` 受版本管理。
