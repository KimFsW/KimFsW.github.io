# ml/ 模型工程

训练、评估与导出（设计方案 2.4 / 11.3）。原始视频与大模型不进 Git，
仓库只保存清单、版本标识、下载脚本、校验哈希与评估结果。

| 子目录 | 作用 |
|---|---|
| `datasets/` | 数据清单与版本管理；分层评估维度见设计方案 10.3 |
| `training/` | PyTorch 训练：人体检测、姿态估计、时序动作分类 |
| `evaluation/` | 召回率/精确率/每摄像头每天误报次数，必须分层统计 |
| `export/` | 导出 ONNX（通用边缘）与 Core ML（Apple 节点），产物进 `edge/inference/` |
