# 守望 AI 可视化演示页

单文件静态页面，无需服务器、无需联网、无外部依赖：

```powershell
# 方式一：命令行打开
start demo\visual\index.html

# 方式二：资源管理器中双击 index.html
```

页面内容：

1. **理念** — 边缘优先 / 多阶段复核 / 报警闭环三原则；
2. **系统工作流** — 摄像头 → 边缘 15 模块 → 云端 → 通知 → iOS，
   鼠标悬停任意模块查看职责、状态（已实现 / 占位）与对应代码文件；
3. **四个虚拟场景** — 老人跌倒（L3）、儿童进入阳台危险区（L2）、
   快速坐下（不报警）、摄像头离线（L1）。
   画面为 SVG 示意图，AI 标注层（检测框、骨架点、区域多边形）与真实系统
   使用同一套归一化坐标体系（设计方案 3.3 节）；
4. **iOS App 操作界面** — 锁屏推送、报警处置、事件中心、区域编辑器，
   四台手机界面串起监护人完整操作流；
5. **事件生命周期** — 状态机图 + 三种结局；
6. **测试地图** — 29 个测试用例与运行指令。

## 可操控模拟器 simulator.html

动画版交互演示（从 `index.html` 导航栏「▶ 模拟器」或 Hero 按钮进入）：

```powershell
start demo\visual\simulator.html
```

用法：

1. 顶部选择场景：**老人跌倒（L3）/ 儿童进入危险区（L2）/ 快速坐下（不报警）/ 摄像头离线（L1）**；
2. 动画自动播放：人物动作 → AI 管线阶段逐个点亮 → 事件上报 → 右侧手机收到推送卡；
3. **点击手机推送卡上的按钮进行处置**：确认风险 → RESOLVED；误报 → FALSE_POSITIVE；
   稍后或不操作 → 超时 ESCALATED，备用联系人接手；
4. 控制条支持暂停/重播/0.5×—4× 变速；危险区场景可用滑块实时调整停留阈值，
   阈值高于实际停留时间则不产生事件（用来理解 ZoneEngine 的触发条件）。

动画规则与 `services/api`、`edge/runtime` 中的真实代码一致：
候选阈值（35%/800ms/60°）、复核静止 20s、L1/L2/L3 通知策略、5 分钟超时升级。

文件结构：

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构、样式、生命周期图 |
| `scenes.js` | 四个场景的 SVG 画面与推理链数据（纯字符串，可在 Node 中测试） |
| `phones.js` | 四个 iOS 界面（锁屏/处置/列表/区域编辑）的 SVG 绘制 |
| `app.js` | 工作流图渲染与交互 |
| `simulator.html` | 可操控模拟器：舞台 SVG、手机、管线/状态机/日志面板 |
| `sim.js` | 时间线动画引擎 + 四场景脚本 + 推送卡交互 |

> 说明：当前场景与手机界面均为 SVG 手绘示意图（环境中无图像生成工具）。
> 若之后需要照片级素材，可用图像生成工具生成后替换 `.cam-frame` 内的
> 场景层，标注层独立成组，无需改动。
