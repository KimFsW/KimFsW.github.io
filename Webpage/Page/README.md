# Page — 网页代码文件夹

存放团队介绍网站的全部页面代码（纯 HTML / CSS / JS 单文件，零依赖、零构建）。

## 页面清单

| 页面 | 文件 | 内容 |
|------|------|------|
| 主页 | `index.html` | Hero 主视觉（团队口号、定位说明、统计数据、心电动画） |
| 团队成员 | `team.html` | 四位成员卡片（照片上传、角色、学历、技能标签） |
| 项目介绍 | `project.html` | 项目「守望 AI（WatchCare AI）」的定位、服务群体、核心功能与痛点分析 |
| 参赛目标 | `goals.html` | 短期目标（赛事期间）与长期愿景（赛事之后） |
| 路演汇报 | `roadshow.html` | 面向评委与合作方的项目路演，涵盖痛点、方案、差异化、商业路径、进展与合作诉求 |

## 说明

- 五个页面共享同一导航条与页脚，点击导航在各页之间跳转；所有页面均提供「路演汇报」入口。
- 设计规范（色彩 / 字体 / 间距 / 组件 / 动效 / 响应式）见 `../Document/Design/DESIGN_SYSTEM.md`。
- 组件选择器清单见 `../Document/Design/COMPONENTS.md`。
- 队员照片资源见 `../Resource/Photos/`。
